# L'Analista — V7

Dashboard personale Serie A derivata dal progetto Excel.

## Novità V7
- Header semplificato con nome provvisorio **L'Analista**.
- Barra Casa/Trasferta fissa durante lo scroll di Dati Match.
- Calendario: Dati Match e Pronostici sempre apribili.
- Fasce 1X2 e 1X2 Poisson (A/B/C/D/NoBet) sui pronostici correnti.
- Pagina Puntate con export CSV delle idee annotate.
- Schedina in preparazione esportabile in CSV.
- Campo puntata, saldo SNAI, vincita potenziale e pulsante **Gioca schedina**.
- Una schedina giocata viene registrata automaticamente nell'Andamento scommesse e scala il saldo.
- Le schedine giocate possono essere chiuse come **Vinte** o **Perse**.
- Le chiavi localStorage di idee, schedina e portafoglio sono rimaste invariate per preservare i dati già salvati nel browser.
